# FUNKO PUMP

Статический сайт, без сборки. Просто залить все файлы в корень репозитория.

- Контракт и ссылку на X вписать в блоке SETTINGS в самом верху index.html
  (window.CONTRACT, window.TWITTER) — остальное подставится само.
- Деплой: GitHub → Vercel, Framework Preset = Other, build command не нужен.
